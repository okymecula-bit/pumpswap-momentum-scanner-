# PumpSwap Momentum Scanner

PumpSwap-only momentum scanner dashboard.

## Rules
- PumpSwap only
- Detect new launches
- Observe candidates from 3–15 minutes
- Coins become eligible at 5+ minutes old
- Require 1-minute confirmation before Telegram alerts
- Perform momentum/on-chain/chart analysis
- No SKIP category

## Run
npm install
npm start

Then open http://localhost:3000
